# Harbor X

Windows releases of **Harbor X**, maintained by **Splash**.

**No installer or update is available yet.** Release preparation is in progress. Downloads will be added only after licensing, corresponding-source, signing, security and release reviews are complete.

This public repository is for release files, update metadata, release notes, and the licenses/notices/corresponding sources required with the distributed components. It does not contain the private development repository or user accounts, settings or credentials.

Future downloads will require no GitHub/Cloudflare account, VPN or extra update client. Stable is the default; Beta is optional and has its own explicit update channel. The app verifies Tauri update signatures and requires approval before installation. The publisher name Splash does not by itself mean Windows Authenticode verification.

Harbor X is based on Harbor. Original Harbor copyright and MIT notices, and all applicable third-party license obligations, remain in force. Public availability does not remove GPL/LGPL corresponding-source requirements.
